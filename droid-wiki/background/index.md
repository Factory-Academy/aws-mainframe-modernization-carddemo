# Background

CardDemo is a migration and modernization demonstration with deliberately varied mainframe patterns (`README.md`). This section explains the conversion material that accompanies the source, without treating suggested target architectures as implemented applications.

- [Modernization](modernization.md): repository-local analysis tools, Java templates, mappings, and validation caveats.
- [Lore](../lore.md): dated changes evidenced by Git history.
- [Architecture](../overview/architecture.md): the current implemented runtime, separate from conversion examples.
